# Machine and ceilings

A rate on its own says nothing: 2.13 GFLOP/s is respectable on one
machine and catastrophic on another. The Machine's ceilings are what
settles it - the roof every roofline placement and every classification
is measured against.

The recipe is short, because the calibration triggers by itself. The
page after it says what a measured ceiling is worth, why a Machine is
not a node, and what happens when nothing can be measured at all.
