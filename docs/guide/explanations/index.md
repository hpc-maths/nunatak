# Explanations

The measurements say where the time goes. They do not say what to change,
and the explanation layer is what asks a language model that question -
from those measurements and the source they point at, and from nothing
else. The model is reached through [pi](https://pi.dev), an external
tool run and parsed like `perf` or `xctrace`.

The recipe comes first: the advice is generated at the end of a run where
the machine allows it, and asked for afterwards where it does not. The
page after it says what the model is given, what it is never given, and
why its answer is stored apart from the facts.
