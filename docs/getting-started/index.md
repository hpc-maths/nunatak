# Getting started

What nunatak is, how to install it, and two tutorials to run with a
machine in front of you.

The first tutorial profiles `examples/stencil` end to end: seven steps,
two runs, a five-line change, and a measured gain. The second profiles
`examples/gemm`, whose rate is known analytically, and checks the
hardware counters against it - which is how you learn what to believe on
a machine you have just arrived on. Both programs ship with this
repository, so the pages can say what you are about to see.
