# Example programs

Two small programs, built for two different purposes: `stencil` to learn
on, with a defect on purpose, and `gemm` to check nunatak's counter path
against a rate known analytically.

```sh
make
./stencil
./gemm
```

What each one is for, what the defect costs and what the analytic check
proves is documented at
[Getting started / The example programs](../docs/getting-started/the-example-programs.md).
